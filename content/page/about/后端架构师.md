# 陈金鑫｜后端架构师 / 微服务系统专家

## 关于我

我是一名后端研发工程师，黑河学院计算机科学与技术专业 2019 届本科毕业。工作经历覆盖广告交易平台、AI 中台、大数据平台、云原生平台、隐私计算平台及数据底座等方向，长期聚焦**高并发分布式系统架构、微服务治理与平台型系统建设**，具备从需求分析、方案设计、核心开发到上线运营的全链路闭环交付能力。

结合历史项目记录，我的技术主线从早期广告交易与实时日志分析（日请求 4 亿+次），逐步演进到 AI 中台与隐私计算平台的后端架构设计与业务交付，再到数据底座场景下的微服务治理与资源调度体系建设。

## 职业定位

- 目标岗位：后端开发工程师（业务架构方向）、技术中台架构师。
- 能力定位：以业务结果驱动的后端架构与研发，偏系统设计、高并发治理与工程效率，而非纯接口开发。
- 核心标签：**Java / Spring Cloud 微服务**、**高并发系统**、**分布式数据平台**、**全链路交付**、**技术驱动业务**。
- 交付特征：不满足于“写接口”，深度参与产品决策与业务判断，对系统质量和最终结果负责。

## 关键成果（基于历史记录）

- **高并发与海量数据处理**：历史版本记录主导广告交易平台（ADX）日均处理请求 **4 亿+次**、日展示 **1 亿+次**、日产生 **TB 级日志**，支撑实时竞价（RTB）与数百家 DSP 厂商对接。
- **微服务架构与治理**：历史版本记录从 0 到 1 建设 AI 中台与统一数据服务平台，采用 **Spring Cloud / Nacos / Eureka** 微服务架构，覆盖网关（APISIX）、权限、监控告警与日志链路，保障核心业务高可用。
- **端到端业务交付**：历史版本记录独立完成“隐私计算模型市场”从需求分析、技术选型、接口开发到 Kubernetes 容器化部署的全流程，推动业务功能快速落地。
- **复杂系统治理与成本优化**：历史版本记录在数据底座方向主导资源与作业监控治理体系建设，覆盖 **300+ 集群**、**1000+ 数据库实例**，推动系统资源利用率提升 **30%+**、整体成本降低 **20%+**。
